# U1.3 — injection-gates (W1.2+W1.3+W1.5)

Same-file bundle: `injectionController.ts`, `ptyClaudeSession.ts`, `remotePermissionHook.ts`,
`pretoolPermissionBridge.ts`, `start.ts`. Turns the single `webTurnActive` boolean into a
self-healing epoch+watchdog, adds a `promptOpen`/`localDraft` injection gate (with a 120s
failsafe) on top of the existing busy/cooldown gate, and wires a real ESC-based `interrupt`
RPC. Followed plan-v2.md's snippets closely; only adaptations are noted below.

## W1.2 — web-turn watchdog + local-submit override

- **`remotePermissionHook.ts`**: replaced the `webTurnActive` boolean with
  `webTurnStartedAt`/`webTurnLastActivityAt` epochs. `isWebTurnActive()` auto-clears
  (logs a warning) once quiet longer than `webTurnMaxMs` (new option, default the new
  exported `WEB_TURN_MAX_MS` = 30 min); a successful check refreshes the activity clock,
  so ongoing hook traffic on a live web turn keeps it alive. New `markLocalActivity()` on
  the handle (a locally-typed Enter reclaims the turn immediately — the same accepted
  "present human beats a remote one" tradeoff the plan documents) and a new injectable
  `now` dep (defaults `Date.now`) so tests can drive the clock deterministically without
  waiting on real timers.
- **`injectionController.ts`**: new public `get isInjecting()` (aliases the existing
  private `injecting` flag) — the local-submit heuristic's "is this synthetic, not the
  human" guard.
- **`ptyClaudeSession.ts`**: new `onLocalSubmit?: () => void` option; `onStdinData` fires
  it on a real `\r`/`\n` seen while `!controller.isInjecting`. (Built directly as the
  final W1.2+W1.3 combined handler — see W1.3 below — rather than as an intermediate
  step that W1.3 would immediately rewrite.)
- **`start.ts`**: wired `onLocalSubmit: () => permHook?.markLocalActivity()` into the PTY
  session options; updated the module doc comment to describe the self-healing model.

## W1.3 — promptOpen/localDraft gates + failsafe + draft classification

- **`injectionController.ts`**: new `promptOpen`/`localDraft` private fields + `PROMPT_OPEN_FAILSAFE_MS`
  (120s) constant. `setPromptOpen(open)` arms/clears a failsafe timer (self-clears via a
  warn-logged recursive call if nothing else ever clears it) and flushes on close;
  `setLocalDraft(active)` flushes on going inactive. `canInject()` now also requires
  `!promptOpen && !localDraft`. `dispose()` cancels the failsafe timer too.
- **`ptyClaudeSession.ts`**: `onStdinData` now classifies local keystrokes (matches the
  plan's `DRAFT_IDLE_MS = 15_000` value): Enter/newline/Escape end a draft
  (`setLocalDraft(false)`, plus `onLocalSubmit` on Enter/newline); any printable char or
  backspace/DEL starts/refreshes one (`setLocalDraft(true)` + a 15s idle timer). New
  handle method `setPromptOpen(open)` → `controller.setPromptOpen(open)`.
- **`pretoolPermissionBridge.ts`**: new `onPromptLikely?: () => void` dep. Fires from
  `handlePreToolUse` only on the local-turn path (`!isWebTurnActive()`) — a web turn's
  `ask` never renders a local dialog, so it must not gate — and from
  `handlePermissionRequest`'s local-`undefined` branch.
- **`remotePermissionHook.ts`**: new `onPromptLikely` option, passed straight through into
  the bridge's deps.
- **`start.ts`**: `onAttention` now sets `ptyHandle?.setPromptOpen(true)` for `"perm"`/`"question"`
  and `false` for `"done"` (previously log-only); new `onPromptLikely: () =>
  ptyHandle?.setPromptOpen(true)` wired into `installRemotePermHook`; `onEnvelopes` now
  wraps the outbox forward with `if (envelopes.some(e => e.ev.t === "tool-end"))
  ptyHandle?.setPromptOpen(false)`.

**Deviation from the plan's snippet**: the plan's `onAttention` replacement only listed
`"perm"` opening the gate; I also included `"question"` (AskUserQuestion/idle-wait
nudges — the other half of `Notification`'s own two cases per `hookServer.ts`'s doc) since
both represent "a TUI dialog is now on screen," and gating only on `"perm"` would leave a
`"question"` prompt un-gated for no documented reason.

## W1.5 — real interrupt (Escape injection)

- **`ptyClaudeSession.ts`**: new handle method `sendInterrupt(): boolean` — writes a
  single `\u001b` (ESC) into the PTY if a child is live, else returns `false`.
- **`start.ts`**: `interrupt` RPC handler replaced `async () => ({ ok: false })` with
  `async () => ({ ok: ptySession.sendInterrupt() })`. `setMode` stays honestly
  not-supported (unchanged — that's W4.3, a separate later unit).

## Tests

- **`injectionController.test.ts`**: `isInjecting` reflects only the write→submit window;
  `promptOpen` gate blocks/flushes/is idempotent/self-clears via the 120s failsafe;
  `localDraft` gate blocks/flushes; both gates are independent (each must clear); both
  setters are no-ops after `dispose()`.
- **`ptyClaudeSession.test.ts`**: added a `makeManualTimers()` harness (the existing
  harness's synchronous `setTimeoutImpl` fires callbacks immediately, which would
  self-defeat any test that needs to observe an in-between gated state) alongside new
  suites: local-submit detection (Enter/newline fire it, ordinary typing doesn't, and a
  real Enter racing in mid-injection is suppressed then fires normally right after);
  local-draft gating (queued injection blocked while composing, released on idle-timeout,
  Enter, or Escape); `setPromptOpen` gating through the controller; `sendInterrupt` writes
  ESC and reports `true`/`false` correctly.
- **`remotePermissionHook.test.ts`**: watchdog expiry past `webTurnMaxMs` (both a
  custom override and the real `WEB_TURN_MAX_MS` default); hook traffic while active
  refreshing the last-activity clock (verified the refresh survives past what would have
  been the original deadline); `markLocalActivity` clearing an active turn immediately;
  `onPromptLikely` forwarding on the local-turn path of both hooks and never firing on
  the web-turn path.
- **`pretoolPermissionBridge.test.ts`**: direct bridge-level `onPromptLikely` coverage —
  fires on `handlePreToolUse`'s local path only, and on `handlePermissionRequest`'s
  local-`undefined` return only.
- **`start.test.ts`**: new wiring tests — `onLocalSubmit` → `markLocalActivity`;
  `onAttention("perm"/"question"/"done")` → `setPromptOpen(true/true/false)`;
  `onPromptLikely` → `setPromptOpen(true)`; a `tool-end` envelope → `setPromptOpen(false)`
  while every envelope still reaches the outbox; existing interrupt/setMode test renamed
  and updated to assert the real `sendInterrupt()` call + `{ok:true}` instead of the old
  honest-`false` stub.

Sub-task 5 (`[human]` live verification: inject-while-prompt-open blocked, draft
survives, interrupt cancels a turn) is out of scope per the task rules and left unchecked.
