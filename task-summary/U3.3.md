No prior attempt: `git log v2-pty-injection..HEAD --oneline` was empty and the
worktree was clean before this session — built from scratch, not a resume.

## What landed

### 1. `packages/web/src/lib/use-machine-crypto.ts` (new)
The shared per-machine DEK-unwrap hook the plan calls for, mirroring
`features/session-control/use-session-crypto.ts` exactly (own crypto-bridge
worker via `useCryptoBridge`, unwraps `MachineRow.dek` off the `['sync']`
snapshot, `null` until `setSessionKey` resolves `true`). Placed in `lib/`
rather than under either consuming feature — same reasoning
`lib/use-sync-snapshot.ts`'s own doc comment gives for why *it* was
extracted out of `session-control` once a second feature needed it: two
feature areas (`new-session`, `git-diff`) need this one, so there's exactly
one place that owns it.

### 2. W3.4 — New Session screen → live spawn
- `features/new-session/live-source.ts` (new): `useLiveNewSessionMachines`
  (decrypts each `MachineRow.metadata`'s `host` off the sync snapshot, same
  decrypt-loop shape `features/session-list/live-source.ts` uses for its own
  machine rows — kept as its own small duplicate here rather than a
  cross-feature import, matching this codebase's existing
  `decryptSessionTitle`/`decryptMachineName` duplication precedent) and
  `useLiveNewSessionActions` (gates on `useMachineCrypto`, falls back to a
  `pendingNewSessionActions()` that rejects every method with an honest
  "not ready yet" message — same shape as `use-live-session-control.ts`'s
  `pendingSessionControl`).
- `new-session-screen.tsx`: default props swapped from
  `useMockNewSessionMachines`/`useMockNewSessionActions` to the two live
  hooks above; doc comment updated. Mocks stay exported for tests/standalone
  review.
- `features/new-session/index.ts` + `app/session/new/page.tsx`: export/doc
  updates reflecting the live wiring.

### 3. W3.5 — Git panel → live
- `features/git-diff/use-live-git-diff-actions.ts` (new): `useLiveGitDiffActions`
  — same `useMachineCrypto`-gated pattern as the New Session actions hook,
  wraps `machineRpcToGitDiffActions(createMachineRpcClient({...}))`.
- `components/GitDiffPanel.tsx`: default `useActions` swapped from
  `useMockGitDiffActions` to `useLiveGitDiffActions`.
- `components/SessionGitScreen.tsx` (new): the session-scoped entry point for
  `/session/[id]/git/`, mirroring `SessionTimelineScreen`'s role. Resolves
  the session's *real* `machineId`/`workspaceId` off the live `['sync']`
  snapshot (`SessionRow.machineId`/`.workspaceId` are plaintext row fields,
  not inside the encrypted `metadata` box — `@falcon/wire`'s `rows.ts`, so no
  decrypt is needed to read them, only the snapshot to have synced), with
  honest loading/not-found/missing-fields states instead of the route's old
  `mach-${id}` / `/workspace/${id}` fabrication.
- `app/session/[id]/git/page.tsx`: now a thin shell rendering
  `<SessionGitScreen sessionId={id} />`, matching `/session/[id]/page.tsx`'s
  existing precedent for `SessionTimelineScreen`.
- `features/git-diff/index.ts`: exports `useLiveGitDiffActions` and
  `SessionGitScreen`.
